플랫폼 사용방법보기

마트관리자에서 모든 운영을 시작합니다

서비스가 활성화되면 마트 사장님은 마트관리자 화면에서 상품 등록, 행사 관리, 푸시알림, 주문 확인, 고객 관리, 쿠폰·포인트 관리 등 플랫폼 운영을 진행합니다.

플랫폼은 매일 복잡하게 관리하는 방식이 아니라, 필요한 내용을 등록하고 고객 반응을 보면서 운영할 수 있도록 구성합니다.

1. 마트관리자 로그인

마트 사장님은 가입 시 등록한 휴대전화번호를 ID로 사용하고, 비밀번호를 입력하여 마트관리자에 로그인합니다.

로그인 후 해당 마트에 발급된 고유 마트코드를 기준으로 해당 마트의 상품, 고객, 주문, QR, 매출, 정산 등의 정보가 연결됩니다.

다른 마트의 정보와 섞이지 않고 각 마트별로 독립적으로 관리됩니다.

비밀번호 변경

로그인한 상태에서 회원정보 변경으로 들어가 비밀번호를 변경할 수 있습니다.

회원정보 변경 → 현재 비밀번호 입력 → 새 비밀번호 입력 → 새 비밀번호 확인 → 변경 완료

비밀번호를 변경해도 휴대전화번호(ID)와 마트코드는 변경되지 않습니다.

비밀번호를 잊어버린 경우

로그인 화면에서 비밀번호 찾기를 선택합니다.

가입할 때 등록한 이메일을 통해 비밀번호 재설정 인증번호가 자동 발송됩니다.

비밀번호 찾기 → 휴대전화번호(ID) 입력 → 등록 이메일로 인증번호 자동 발송 → 인증번호 입력 → 새 비밀번호 설정

본인 인증이 완료되면 새로운 비밀번호를 설정할 수 있습니다.

2. 마트 기본정보 관리

마트관리자에서 등록된 마트 정보를 관리할 수 있습니다.

기본정보는 다음과 같습니다.

마트명 · 대표자명 · 사업자등록번호 · 마트 주소 · 담당자명 · 휴대전화번호 · 이메일 · 마트코드 · 서비스 상태

마트 정보가 변경된 경우 필요한 내용을 수정하여 최신 상태로 관리합니다.

3. 상품을 등록합니다

마트에서 판매할 상품을 마트관리자에서 직접 등록합니다.

상품 등록 시 기본적으로 다음 내용을 입력합니다.

상품사진 · 상품명 · 정상가격 · 판매가격 · 할인정보 · 상품구분 · 판매상태

등록한 상품은 고객이 보는 디지털 화면에 자동으로 반영됩니다.

상품 가격이나 사진이 변경되면 마트관리자에서 바로 수정할 수 있습니다.

4. 상품 종류를 구분하여 운영합니다

상품은 운영 목적에 따라 구분하여 등록합니다.

특가상품 최대 30개 고객의 관심을 빠르게 끌 수 있는 할인상품이나 한정판매 상품을 등록합니다.
행사상품 최대 50개 마트에서 진행하는 행사상품을 등록합니다.
공동구매 최대 6개 고객의 신청수량을 모아 판매하는 공동구매 상품을 운영합니다.
일반상품 최대 200개 마트에서 일반적으로 판매하는 상품을 등록합니다.

전체적으로 최대 286개의 상품을 운영할 수 있습니다.

5. 상품 내용을 필요할 때 바로 수정합니다

마트의 판매상황에 따라 상품은 언제든지 수정할 수 있습니다.

예를 들어 가격이 변경되거나 재고가 소진된 경우 해당 상품의 내용을 변경합니다.

가격 변경 → 할인율 변경 → 사진 변경 → 판매중지 → 다시 판매

마트 상황에 맞게 직접 관리할 수 있습니다.

6. 행사와 특가상품을 우선적으로 운영합니다

고객의 방문을 유도하려면 일반상품만 등록하는 것보다 특가상품과 행사상품을 지속적으로 관리하는 것이 중요합니다.

마트 사장님은 해당 주의 행사상품이나 판매를 집중하고 싶은 상품을 먼저 등록합니다.

상품이 등록되면 고객의 디지털 화면에 자동으로 반영됩니다.

7. 푸시알림을 발송합니다

상품과 행사내용을 등록한 후 고객에게 푸시알림을 발송합니다.

푸시알림은 마트당 주 2회까지 발송합니다.

푸시알림 발송비용은 0원입니다.

마트는 고객에게 알리고 싶은 특가, 행사, 공동구매 등의 내용을 선택하여 발송합니다.

상품 등록 → 푸시알림 발송 → 고객 알림 수신 → 디지털 화면 접속

너무 많은 알림을 보내지 않고 주 2회 범위에서 필요한 내용을 집중적으로 전달합니다.

8. 고객은 디지털 화면에서 상품을 확인합니다

푸시알림을 받은 고객은 알림을 눌러 해당 마트의 디지털 화면으로 들어옵니다.

고객은 등록된 특가상품, 행사상품, 공동구매상품, 일반상품을 볼 수 있습니다.

마트에서 상품정보를 수정하면 고객의 디지털 화면에도 자동으로 반영됩니다.

9. 주문이 들어오면 마트관리자에 자동으로 표시됩니다

고객이 상품을 주문하면 주문내용이 마트관리자 주문내역에 자동으로 표시됩니다.

다음 내용을 볼 수 있습니다.

고객 · 주문상품 · 수량 · 주문시간 · 수령방법 · 주문상태

전화주문처럼 별도로 메모할 필요 없이 고객이 주문한 내용이 마트관리자에 자동으로 들어옵니다.

10. 주문상태를 관리합니다

접수된 주문은 진행상황에 따라 주문상태를 변경합니다.

주문접수 → 상품준비 → 배달 또는 방문수령 → 완료

마트에서는 상품 준비와 실제 전달에 필요한 부분만 처리합니다.

11. 공동구매 신청수량이 자동으로 집계됩니다

고객이 공동구매를 신청하면 상품별 신청수량이 자동으로 집계됩니다.

마트 사장님은 집계된 수량을 보고 준비할 상품 수량을 결정합니다.

공동구매 등록 → 고객 신청 → 신청수량 자동집계 → 상품준비 → 판매

고객의 신청수량을 별도로 계산할 필요 없이 마트관리자에서 볼 수 있습니다.

12. 배달 주문을 처리합니다

고객이 배달을 선택하면 해당 주문이 배달 주문으로 구분되어 표시됩니다.

마트에서는 주문에 맞춰 상품을 준비한 후 고객에게 배달합니다.

배달 주문은 온라인 사전결제가 아니라 배달 현장에서 결제합니다.

배달 시 고객에게 영수증을 제공하고 영수증에는 포인트 적립 내역이 표시됩니다.

배달 주문 → 상품 준비 → 상품 배달 → 영수증 제공 → 포인트 적립 → 현장결제

13. 방문 수령 주문을 처리합니다

고객이 방문 수령을 선택하면 해당 주문이 방문 수령으로 구분되어 표시됩니다.

고객이 방문하기 전에 주문상품을 준비하고, 고객이 마트에 방문하면 상품을 전달합니다.

주문접수 → 상품 준비 → 고객 방문 → 상품 수령

14. 쿠폰을 사용합니다

분양사 공유 신청을 통해 고객에게 쿠폰이 제공된 경우 고객은 앱에서 쿠폰을 제시합니다.

고객 쿠폰 제시 → QR 스캔 → 쿠폰 상태 자동판별 → 혜택 적용

쿠폰의 사용기간과 사용조건에 따라 사용 가능 여부가 처리됩니다.

15. 권총형 스캐너로 쿠폰 QR을 스캔합니다

현장에서는 권총형 스캐너를 이용하여 고객의 쿠폰 QR을 스캔합니다.

QR을 스캔하면 시스템에서 해당 쿠폰의 상태를 자동으로 판별합니다.

쿠폰 QR 제시 → 권총형 스캐너 스캔 → 사용 가능 여부 자동판별 → 혜택 적용

사용 완료된 쿠폰은 다시 사용할 수 없도록 처리됩니다.

16. 고객 포인트를 사용합니다

분양사 공유 신청 시 분양사에서 고객에게 포인트가 지급됩니다.

고객이 해당 마트에서 포인트를 사용하면 포인트 사용내역이 자동으로 기록됩니다.

고객 포인트 보유 → 마트 방문 → 포인트 사용 → 사용내역 자동기록

마트에서는 별도로 포인트 사용내역을 작성할 필요가 없습니다.

17. 자동차 QR 등록 고객이 자동으로 연결됩니다

마트에서 자동차 QR을 무료로 제공한 고객은 앱과 푸시알림을 등록한 후 자동차 QR을 사용할 수 있습니다.

고객이 자동차 QR을 등록하면 해당 마트의 디지털 고객으로 자동 연결됩니다.

기존 고객과 신규 고객이 QR을 통해 디지털 회원으로 전환되면서 해당 마트의 고객 기반이 축적됩니다.

18. 차량이 없는 고객도 디지털 회원으로 연결됩니다

차량이 없는 고객은 마트 입구 QR을 통해 앱을 설치하고 푸시알림을 등록할 수 있습니다.

등록이 완료되면 해당 마트의 디지털 고객으로 연결됩니다.

따라서 자동차 QR 고객뿐 아니라 입구 QR을 이용한 고객도 마트의 디지털 고객으로 축적됩니다.

19. 고객정보가 마트코드로 관리됩니다

해당 마트와 연결된 고객정보는 고유 마트코드를 기준으로 자동 분류되어 관리됩니다.

신규 디지털 회원이 증가할수록 해당 마트에 연결된 고객 기반도 함께 증가합니다.

마트는 이렇게 축적된 디지털 고객에게 주 2회 범위에서 푸시알림을 발송할 수 있습니다.

20. 판매와 고객 반응을 관리합니다

마트관리자에서는 등록한 상품, 고객 주문, 공동구매 신청, 쿠폰·포인트 사용 등의 운영정보를 볼 수 있습니다.

마트 사장님은 이 정보를 바탕으로 어떤 상품과 행사를 운영할지 결정하고 다음 상품과 행사에 활용합니다.

매주 이렇게 운영하면 됩니다

플랫폼 운영을 복잡하게 생각할 필요가 없습니다.

마트 사장님이 직접 해야 하는 기본적인 운영은 다음과 같습니다.

① 판매할 상품과 행사상품 결정
↓
② 마트관리자에서 상품 등록·수정
↓
③ 주 2회 범위에서 푸시알림 발송
↓
④ 접수된 주문에 맞춰 상품 준비
↓
⑤ 배달·방문수령 처리
↓
⑥ 다음 행사상품 등록

상품 반영, 주문 접수, 공동구매 수량 집계, 고객 연결, 포인트 사용기록 등 시스템에서 자동으로 처리되는 부분은 마트 사장님이 별도로 확인 작업을 반복하지 않도록 운영합니다.

마트관리자에서 직접 운영하세요

마트 사장님은 상품 등록·수정, 행사 운영, 푸시알림 발송, 주문에 따른 상품 준비와 전달 등 실제 운영에 필요한 업무를 마트관리자에서 처리합니다.

그 외 시스템에서 자동으로 처리할 수 있는 부분은 자동화하여 마트 사장님의 관리업무를 최대한 줄이는 것이 플랫폼 운영의 기본입니다.
