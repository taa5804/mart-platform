주문한 상품을 편리하게 받아보세요

마트에서 주문한 상품을 고객의 상황에 맞게 배달 또는 방문 수령으로 이용할 수 있습니다.

배달 서비스

주문한 상품을 집에서 편리하게 받아볼 수 있습니다.

상품 주문 → 배달 선택 → 주문 확인 → 상품 배달

마트는 주문내용을 확인하고 고객에게 상품을 전달합니다.

방문 수령 서비스

직접 마트에 방문하여 상품을 받을 수도 있습니다.

상품 주문 → 방문 수령 선택 → 주문 확인 → 마트 방문 → 상품 수령

고객이 원하는 방식으로 상품을 받을 수 있어 편리합니다.

배달 시 영수증 포인트 적립과 현장결제

배달 주문의 경우 배달 시 영수증을 함께 제공하고, 영수증에는 포인트 적립 내역이 표시됩니다.

결제는 온라인에서 미리 결제하는 방식이 아니라 배달 현장에서 결제합니다.

배달 주문 → 상품 배달 → 영수증 확인 → 포인트 적립 → 현장결제

고객은 상품을 받은 후 영수증을 확인하고 현장에서 결제하며, 구매에 따른 포인트도 함께 적립됩니다.

분양사 공유 신청 시 쿠폰을 사용할 수 있습니다

분양사 공유 신청 시, 분양사에서 제공하는 쿠폰을 고객이 마트에서 사용할 수 있습니다.

고객은 앱에서 쿠폰을 확인한 후 마트 방문 시 쿠폰을 제시하면 됩니다.

분양사 공유 신청 → 쿠폰 발급 → 앱에서 쿠폰 확인 → 마트 방문 → 쿠폰 제시 → 쿠폰 확인 → 혜택 적용
쿠폰에는 사용기간과 사용조건이 표시되며, 유효기간이 지나면 사용할 수 없습니다.

권총형 스캐너로 간편하게 확인

마트에서는 권총형 스캐너로 고객의 쿠폰 QR을 스캔하여 쿠폰 사용 여부를 간편하게 확인할 수 있습니다.

고객 쿠폰 QR 제시 → 권총형 스캐너로 스캔 → 쿠폰 확인 → 혜택 적용

복잡한 확인 절차 없이 현장에서 바로 확인할 수 있어 고객과 마트 모두 편리하게 쿠폰을 사용할 수 있습니다.

분양사 공유 신청 시 포인트가 지급됩니다

분양사 공유 신청 시, 고객에게 제공되는 포인트는 분양사에서 지급합니다.

지급된 포인트는 당신의 마트에서만 사용할 수 있어, 고객의 마트 방문과 상품 구매로 연결됩니다.

분양사 공유 신청 → 분양사 포인트 지급 → 고객 포인트 보유 → 당신의 마트에서 사용 → 상품 구매

쿠폰과 포인트가 고객을 마트로 연결합니다

분양사 공유 신청 시 제공되는 쿠폰과 포인트를 통해 고객의 마트 방문을 유도하고, 쿠폰·포인트를 사용하면서 추가 상품을 구매할 수 있어 추가 구매 효과도 기대할 수 있습니다.

분양사 공유 신청 → 고객 혜택 → 마트 방문 → 쿠폰·포인트 사용 → 추가 구매 → 마트 매출 증가
분양사 공유 신청을 통해 고객 혜택을 연결하고 마트 방문과 추가 구매로 이어지도록 합니다.
