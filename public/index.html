마트로 자주 묻는 질문 (FAQ)

질문을 누르면 상세한 답변을 바로 확인하실 수 있습니다.

Q1. 마트 신규 고객 유치와 입주민 DB 확보는 어떻게 이루어지나요? ▼
(1) 기존 포스 DB 고객 문자 링크 전환 + (2) 마트 입구 입간판 QR + (3) 비노출 주차 안심 QR 3가지 방식으로 완벽 확보합니다. 1. 기존 포스 DB 고객 문자 전환: 마트가 보유한 기존 고객에게 "디지털 전단지 전환 안내" 문자를 보내면, 고객이 링크 클릭 후 [🔔 특가 알림 허용]을 1초 만에 눌러 발송비 0원 푸시 단골로 즉시 등록됩니다.
2. 마트 입구 입간판 QR: 매장을 방문하는 도보·대중교통 고객이 입구 배너 QR을 스캔하여 앱 설치 및 특가 알림을 등록합니다.
3. 아파트 자차 안심주차 QR: 아파트 입주민 차량에 부착할 수 있는 개인 번호 미노출 안심 주차 QR을 무료 배포하여 등록 시 푸시 알림을 수신하도록 연동합니다.
이를 통해 마트 사장님은 기존 단골 고객을 100% 그대로 계승하면서 신규 아파트 입주민 DB까지 빈틈없이 확보합니다.
Q2. 기존 종이 전단지나 LMS 문자와 무엇이 다른가요? ▼
글자만 빽빽한 스팸 문자 대신, 4대 카테고리 상품이 선명한 디지털 화면으로 보여지며 주문·방문·배달이 모두 이루어집니다. - 4대 상품 디지털 노출: 오늘의 특가(aT 데이터 기반 가격 급락 특가품), 행사상품(매장 세일), 공동구매(묶음 할인), 일반상품(상시 판매품)
- 원스톱 구매 연결: 고화질 사진과 가격을 보면서 입주민이 손가락 터치 한 번으로 앱 내 직접 주문, 집 앞 배달 요청, 매장 직접 방문 구매까지 모든 거래가 자연스럽게 이어집니다.
Q3. 마트 이용 비용과 정산 구조는 어떻게 되나요? ▼
매달 수십~수백만 원씩 낭비되던 문자 발송비 대신 합리적인 월 정액 가맹비로 대폭 절감됩니다. 보낼 때마다 건당 비용(30~50원)이 계속 누적되는 일반 문자와 달리, 합리적인 월 가맹비 하나로 무제한 디지털 전단지 전송과 우리아파트 입주민 단골 고객 DB 관리 혜택을 모두 누리실 수 있습니다.
Q4. 기존 매장에서 쓰던 포스(POS) 기기를 교체해야 하나요? ▼
아닙니다. 기존 사용하시던 POS 기기 그대로 사용하시며, 사장님이 상품을 직접 업로드하시면 됩니다. 비싼 전용 단말기나 기기 교체 비용이 일체 없으며, 매장 PC나 스마트폰에서 터치 몇 번으로 오늘의 특가, 행사상품, 사진 등을 사장님이 직접 간편하게 업로드하여 실시간으로 입주민에게 전송할 수 있습니다.
Q5. 마트 실제 매출에는 어떻게 직접적인 도움이 되나요? ▼
디지털 전환 + 원스톱 주문·배달 + 분양사 쿠폰 연동으로 매출이 확실하게 올라갑니다. 1. 디지털 사진 전단지 전환: 단순 텍스트 문자가 아닌 고화질 사진 전단지로 당일 특가 상품의 구매력을 극대화합니다.
2. 주문·배달·방문 자동 연결: 전단지를 본 입주민이 터치 한 번으로 직접 주문, 배달 신청, 매장 방문 구매까지 자동으로 이어집니다.
3. 분양사 광고 연동 마트 전용 쿠폰: 마트 "오늘의 특가" 하단에 노출된 분양사 광고를 입주민이 클릭하면 전자쿠폰이 즉시 지급되며, 이 쿠폰은 해당 전단지를 발행한 우리 마트 매장에서만 사용 가능하여 입주민의 매장 방문과 추가 장보기를 강력하게 이끌어냅니다.
