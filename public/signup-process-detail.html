가입절차보기

간단한 가입 신청으로 시작하세요

우리아파트 마트 플랫폼은 마트 정보를 입력하고 필요한 서류를 등록하면 가입 신청을 할 수 있습니다.

본사 확인과 이용료 입금이 완료되면 마트코드가 발급되고 플랫폼을 이용할 수 있습니다.

1. 마트 기본정보 입력

가입 신청 시 다음 정보를 입력합니다.

마트명 · 대표자명 · 사업자등록번호 · 마트 주소 · 담당자명 · 휴대전화번호(ID) · 비밀번호 · 이메일

휴대전화번호는 로그인 시 사용하는 ID로 이용합니다.

이메일은 비밀번호 확인 및 계정관리에 사용합니다.

2. 필수서류 3가지 등록

가입 신청 시 다음 3가지 서류를 등록합니다.

① 사업자등록증

마트의 사업자 정보를 확인하기 위한 서류입니다.

② 고객 DB 자료

최근 1년간의 고객 DB 자료를 등록합니다.

영업기간이 1년 미만인 신규 마트는 영업 시작일부터 현재까지의 자료를 등록하면 됩니다.

③ 매출자료

최근 1년간의 매출자료를 등록합니다.

영업기간이 1년 미만인 신규 마트는 영업 시작일부터 현재까지의 자료를 등록하면 됩니다.

3가지 필수서류가 모두 등록되어야 가입 신청이 완료됩니다.

3. 가입 신청

마트 정보와 필수서류 3가지를 모두 등록하고 가입 신청을 완료합니다.

가입 신청이 접수되면 상태가 본사 승인 대기로 전환됩니다.

4. 본사 확인 및 승인

본사에서 가입정보와 제출된 서류를 확인합니다.

확인이 완료되면 가입을 승인하고 해당 마트의 플랫폼 이용료를 안내합니다.

5. 이용료 안내

가입이 승인되면 마트 사장님에게 입금계좌와 납부할 이용료가 자동으로 안내됩니다.

안내된 계좌로 이용료를 입금하면 다음 단계로 진행됩니다.

6. 입금 확인 및 서비스 활성화

이용료 입금이 확인되면 해당 마트의 서비스가 활성화됩니다.

서비스가 활성화되면서 마트 운영에 필요한 고유 마트코드가 발급됩니다.

마트코드는 해당 마트의 고객, QR, 주문, 매출, 정산 등의 정보를 연결하는 고유번호로 사용됩니다.

7. 플랫폼 이용 시작

서비스가 활성화되면 마트 플랫폼을 사용할 수 있습니다.

이후 마트에서 고객을 등록하고 상품과 행사정보를 운영하면서 플랫폼 서비스를 이용하게 됩니다.

마트 사장님은 마트관리자 화면에서 상품사진, 상품명, 가격, 할인정보, 특가상품, 행사상품, 공동구매상품, 일반상품 등의 상품과 내용을 직접 등록·수정하고 관리합니다.

등록한 상품과 내용은 고객이 이용하는 디지털 화면에 반영됩니다.

마트관리자 접속 → 상품·내용 등록 → 디지털 화면 반영 → 고객에게 푸시알림 → 고객 상품 확인
