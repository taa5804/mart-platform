"첫 가입 1,000건 무료 지원 + 문자 발송 건당 15원 + 동네 단골 유입 플랫폼"
마트 사장님이 무조건 반길 수밖에 없는 압도적 무기로 평생 내 전담 마트와 지속적인 자동 수익을 만드세요!

🎁 첫 가입 1,000건 무료 문자 💬 문자 1건당 5원 적립 🔑 전용 4자리 영업코드 영구 락 📂 POS 엑셀 1초 등록
1

전용 영업코드 발급 및 마트 평생 귀속 방법

한 번 등록한 마트는 전산상 평생 본인의 전담 관리 마트로 영구 락(Lock) 귀속됩니다.

1단계
간편 신청 및 본사 승인

하단 신청서에 성함과 연락처를 남기시면 본사 대표님 직통 확인 후 본인 전용 4자리 영업코드(예: 5804)가 문자로 즉시 발급됩니다.

2단계
메인화면 우측상단 영업코드 입력

현장 마트에 방문하여 스마트폰이나 마트 카운터 PC로 플랫폼 접속 후, 메인화면 우측상단에 승인받은 [영업코드 4자리]를 입력하면 전용 영업·관리방이 열립니다.

3단계
평생 전산 락(Lock) 귀속

영업방에서 마트 정보를 등록하는 순간, 해당 마트는 본인의 평생 전담 관리 마트로 전산에 영구 락(Lock) 귀속되며 타 영업자가 절대 가로챌 수 없습니다.

2

영업 파트너 수익률 및 매월 정산 구조

담당 마트가 문자를 쏠 때마다 문자 1건당 정확히 5원씩 본인 통장으로 자동 적립됩니다.

문자 건당 영업인 적립금 건당 5원 적립
마트 1곳 평균 월간 발송량 월 15,000건 ~ 80,000건
마트 1곳당 월간 연금 수익 매월 75,000원 ~ 400,000원
마트 10곳 관리 시 월간 연금 수익 매월 75만 원 ~ 400만 원!
마트 20곳 관리 시 월간 연금 수익 매월 150만 원 ~ 800만 원!
추가수익
간편 주문·방문포장 결제 수수료 배분

마트 고객들이 별도 복잡한 앱 설치 없이 전송받은 화면을 통해 간편하게 장을 보고 주문·결제할 때마다 플랫폼 결제 수수료의 일부가 매월 추가 정산됩니다.

평생보장
영구 누적형 패시브 인컴

확보한 마트가 장사를 계속하는 한 매달 가만히 있어도 안정적인 자동 수익이 평생 보장됩니다.

3

현장 영업 핵심 무기 (마트 사장님 100% 설득 화법)

1,000건 무료 체험에 비용은 70% 깎아주는데 거절할 마트 사장님은 없습니다.

🎯 멘트 1: "사장님, 부담 없이 써보시라고 첫 가입 시 문자 1,000건을 무료로 먼저 쏴드립니다!"

돈 1원도 들이지 않고 효과부터 검증해 보실 수 있도록 본사에서 첫 가입 즉시 1,000건 무료 발송(0원)을 전액 지원해 드린다고 제안하세요. (가장 강력한 계약 무기!)

🎯 멘트 2: "무료 체험 후에도 종이 전단지와 비싼 문자 비용을 70% 줄여드립니다."

일반 문자 대행사의 40~50원짜리 비싼 링크 문자 대신, 컬러 사진 전단지가 1초 만에 스마트하게 열리는 문자를 국내 최저가인 건당 15원에 평생 쓰실 수 있게 세팅해 드린다고 브리핑하세요.

🎯 멘트 3: "자동차 QR 스티커는 동네 주민들을 우리 마트로 끌어모으는 최고의 [고객 유입 수단]입니다."

아파트 주민들이 차에 부착된 QR을 찍고 마트 할인 쿠폰을 받아 매장으로 찾아오게 만드는 가장 강력한 신규 고객 유입 및 단골 DB 확보 도구임을 확실하게 강조하세요.

4

실전 마트 영업 방법 (계약 성사 4단계 실전 프로세스)

현장에서 실제로 마트를 발굴하고 당일 계약까지 이끌어내는 표준 실전 영업 매뉴얼입니다.

1단계
타겟 마트 발굴 (아파트 상권 중대형·식자재·로컬푸드 마트)

관할 지역 내 매주 목·금 주말 세일 문자를 발송하거나 종이 전단지를 돌리는 아파트 상가 마트, 식자재 마트, 청과야채 전문점을 1순위로 리스트업합니다.

2단계
점장/대표 미팅 및 '1,000건 무료 체험' 제안

"사장님, 매달 전단지와 문자비 수백만 원씩 나가시죠? 본사에서 첫 가입 1,000건 무료 발송을 지원해 드리니 돈 1원도 안 들이고 효과 먼저 확인해 보세요!" 화법으로 진입 장벽을 완전히 허뭅니다.

3단계
스마트폰 현장 시연 (1초 컬러 전단 화면 보여주기)

영업인의 스마트폰으로 실제 마트 행사 상품 화면과 주문 시스템이 1초 만에 깔끔하게 열리는 샘플을 사장님 눈앞에서 직접 터치하며 보여드립니다.

4단계
당일 즉시 계약 클로징 및 엑셀 등록

마트 카운터 POS(포스기)에서 고객 번호 엑셀을 뽑아 메인화면 영업방에 등록하고, 사장님과 함께 첫 1,000건 무료 문자를 바로 세팅하여 당일 계약을 완벽히 마무리지으세요!

5

마트 POS(포스기) 고객 엑셀 DB 등록 완벽 실무 매뉴얼

영업인이 현장에서 1초도 헤매지 않도록, 포스기에서 엑셀을 바탕화면으로 빼내는 과정부터 [방법1(포스기 직접 등록)]과 [방법2(스마트폰 전송 등록)]까지 순서대로 정리한 실무 매뉴얼입니다.

사전 필수 준비

🖥️ POS(포스기)에서 고객 번호 엑셀 바탕화면으로 저장하는 법

마트 사장님들은 평소에도 할인 문자를 보낼 때 고객 엑셀을 자주 뽑으십니다. 아래 요령으로 사장님께 말씀드리거나 직접 30초 만에 바탕화면에 저장하십시오.

💬 사장님께 건넬 가장 쉬운 한마디: "사장님, 평소 주말 세일 문자 보내실 때 쓰시는 고객 전화번호 엑셀 명단, 포스기 바탕화면에 파일 하나만 쓱 뽑아주세요!" ➔ 사장님이 매주 하시는 작업이라 10초 만에 바로 바탕화면에 엑셀을 빼주십니다.
직접 포스기 화면에서 뽑을 경우 (전국 포스기 3단계 공통):
1. 포스기 화면 상단의 [회원 관리] 또는 [고객 관리] 메뉴 클릭
2. [전체 회원 조회 / 검색] 버튼 클릭 ➔ 화면에 고객 목록이 뜸
3. 우측 상단이나 하단의 [엑셀 다운로드 / 엑셀 저장] 버튼 클릭 ➔ 저장 위치를 찾기 쉽게 [바탕화면]으로 선택 후 저장! (예: 마트고객.xlsx)
방법 1 (강력 추천 10초 컷)

포스기 인터넷 창에서 즉시 등록 (파일 이동 없음!)

프로그램 설치 X / 웹 접속

포스기 바탕화면에 엑셀이 이미 있으므로, 포스기 인터넷 창으로 접속해 드래그 앤 드롭으로 10초 만에 끝내는 가장 빠른 방법입니다.

1-1단계
포스기 화면에서 인터넷 브라우저(크롬 또는 엣지) 열기

포스기도 일반 윈도우 컴퓨터입니다. 바탕화면이나 하단 작업표시줄의 인터넷 창(크롬/엣지)을 엽니다. (포스기에 어떤 프로그램도 깔 필요가 없습니다)

1-2단계
주소창에 wooriapt.ai.kr 입력 ➔ 우측상단 영업코드 입력

인터넷 주소창에 wooriapt.ai.kr을 치고 들어간 뒤, 메인화면 오른쪽 상단의 [🔑 영업코드] 입력칸에 본인의 승인된 4자리 코드를 넣고 [내 방 입장]을 클릭합니다.

1-3단계
내 전용 방에서 바탕화면 엑셀 파일을 마우스로 쓱 끌어다 놓기!

열린 내 방에서 마트명과 사장님 휴대폰 번호를 적고, 화면 가운데 [📁 마트 고객 엑셀 파일 저장란]으로 바탕화면의 엑셀 파일을 마우스로 끌어다 놓습니다(드래그 앤 드롭). (클릭하여 파일 선택 창에서 바탕화면 엑셀을 선택하셔도 됩니다)

1-4단계
[마트 등록 완료] 클릭 ➔ 즉시 1,000건 무료 문자 세팅 & 건당 5원 가동!

등록 버튼을 누르면 AI가 010 번호만 1초 만에 깔끔하게 정제하여 등록합니다. 사장님 앞에서 첫 1,000건 무료 혜택을 즉시 확인시켜 드리고, 마트가 문자를 쏠 때마다 건당 5원씩 평생 자동 적립됩니다!

방법 2 (모바일 전용)

영업인 스마트폰으로 엑셀 전송받아 등록하기

카톡 전송 활용

포스기 컴퓨터를 직접 만지기 어렵거나, 영업인 본인의 스마트폰으로만 깔끔하게 등록하고자 할 때 사용하는 방법입니다.

2-1단계
포스기 바탕화면 엑셀을 내 카카오톡으로 전송받기

사장님께 "사장님, 바탕화면에 뽑아두신 엑셀 파일 제 카톡으로 파일 전송 하나만 부탁드립니다"라고 하거나, 포스기 PC 카톡(나와의 채팅)을 이용해 엑셀을 전송합니다. (이메일/USB로 넘겨받으셔도 무방합니다)

2-2단계
스마트폰 카카오톡에서 엑셀 파일 [다운로드(폰 저장)]

스마트폰 카톡 채팅방에서 전송받은 엑셀 파일을 터치하여 스마트폰 내부(다운로드 폴더)에 저장합니다.

2-3단계
스마트폰 브라우저로 wooriapt.ai.kr 접속 ➔ 영업코드 입력

스마트폰에서 인터넷 창을 열고 wooriapt.ai.kr 접속 후, 우측 상단 [🔑 영업코드]에 4자리 코드를 치고 [내 방 입장]을 터치합니다.

2-4단계
마트 정보 입력 후 [📁 엑셀 파일 저장란] 터치 ➔ 파일 선택 및 완료!

마트 정보를 적고 화면 중앙의 [📁 엑셀 파일 저장란]을 손가락으로 터치하여, 폰 '다운로드' 폴더에 저장된 엑셀 파일을 선택하고 등록 버튼을 누르면 전산 세팅이 1초 만에 끝납니다!

※ 신청 즉시 본사 대표님 휴대폰(010-2286-4150)으로 승인 요청 문자가 전송되며, 확인 즉시 본인만의 전용 영업코드가 문자로 발송됩니다.
※ 정산 통장 계좌번호는 첫 마트 계약 완료 후 실제 수익 정산 시 안전하게 등록합니다.
